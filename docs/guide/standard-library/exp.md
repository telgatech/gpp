# `gpp/exp`

`gpp/exp` contains experimental standard library packages. Their APIs may
change as they evolve.

## Subpackages

- [`gpp/exp/cache`](./exp-cache) — Typed GOB cache with TTL and a replaceable byte store.
- [`gpp/exp/http`](./exp-http) — HTTP client with typed JSON helpers and cookie persistence.
- [`gpp/exp/queue`](./exp-queue) — Durable, single-process work queue with priorities and retries.
- [`gpp/exp/workflow`](./exp-workflow) — Durable state machines with branches, waits, and retries.
